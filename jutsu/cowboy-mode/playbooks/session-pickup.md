# Session pickup

1. **Find the work.** The branch, its worktree, uncommitted changes, the last commits, any open PR, and the Alabasta task if one is named.
2. **Rebuild the goal.** From the task, the previous session's summary and the commits: what was asked, what is done, what is half-done. Write it as a short brief.
3. **Check the state is sound.** Does it build and pass checks right now? Is the branch behind the default branch? Resolve conflicts by understanding both sides; never drop the other side's intent.
4. **Commit what is already good** before changing anything, so the pickup point is recoverable.
5. **Continue** with the playbook the original work used.
6. **Report** what you found, what you finished, and anything from the previous session you could not confirm.
